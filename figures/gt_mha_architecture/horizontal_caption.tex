\caption{\textbf{GT-MHA generates multiple attention heads from shared bases.}
Token embeddings are projected through $C$ learned query/key/value projection triples (three base families illustrated). Shared generator banks and head-specific mixing coefficients produce transformations for the query--key and value paths. The integrated tangent-plane/manifold schematic illustrates the exact exponential construction; the residual variant uses $I+A$. Each head combines its assigned base features (solid connections) with its learned transformations (dashed connections), computes attention and aggregates values. Head outputs are concatenated and projected to the model dimension. Colors identify base families; attention patterns are illustrative rather than measured.}
\label{fig:gt-mha-architecture}
